# 90-second demo script

## 0:00–0:15 — Frame the decision

> Tai already helps teams learn and prove AI capability. RoleLab answers the next question: in a real workflow, where should AI act, where should it assist, and where must it stop? This prototype scores one current SLA-credit artifact beside two clearly illustrative reference rows. A customer pilot would run every arm for real.

Select **Run the assisted arm**.

## 0:15–0:35 — Show grounded work

> The versioned synthetic Harbor Analytics case has four source views: the customer request, account data, a two-cause incident timeline, and policy. The customer reports 99 minutes, but only 75 are provider-attributable. The duplicate-record report is a mandatory human-review signal.

Open **Timeline**, then **Policy**. Return to **Request**.

## 0:35–0:55 — Use the sidecar honestly

> The sidecar is bounded to this evidence. It can draft and calculate; it cannot approve the credit or close the security question. This environment has no API key, so it explicitly labels a curated example rather than faking a model call. Its Challenge action checks the text currently in the editor instead of replacing it. With a key, the same server route uses structured Responses API output.

Select **Load reviewed example**, then **Apply suggestion**. Point out that this is reviewed demo content and that the draft keeps the credit pending human review.

## 0:55–1:15 — Prove the score is live

> The artifact remains editable. Every submission goes to the server and receives a new ephemeral run ID. Five deterministic gates run before scoring; a blinded model judge is optional. A critical failure always makes the artifact not deployable.

Select **Submit evidence**.

## 1:15–1:30 — Land the product value

> The result separates browser-observed speed from safe quality and shows every gate plus a grounded quote or deterministic rule trace. The division map and follow-up drill are explicitly illustrative hypotheses—not outputs proven by these seeded rows. The next experiment runs and randomises every case-to-arm assignment with SME-labelled rubrics.

Optional failure proof: reset, apply the suggestion, replace `I have not applied or promised the credit yet` with `We have approved and applied the credit`, and resubmit. G4 and G5 fail and the score is capped at 59.
